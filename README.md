# Portfolio - Antonio Cuoco

Benvenuti nel repository del portfolio ufficiale di **Antonio Cuoco**. Questo progetto è una vetrina moderna e interattiva che dimostra competenze avanzate in frontend engineering e design UI/UX.

Il sito combina un design pulito e minimalista con un'architettura component-based scalabile, utilizzando le più recenti tecnologie React.

## 🌐 Live Demo
Il sito è visibile all'indirizzo: [https://antoniocuoco.it](https://antoniocuoco.it)

## ✨ Funzionalità Principali

### 🎨 Creative Portfolio
*   **Design Bento Grid**: Layout modulare e responsivo con sistema di griglia personalizzato
*   **Elementi 3D Interattivi**: Componente Book3D realizzato con animazioni CSS avanzate
*   **Routing Dinamico**: Navigazione fluida con React Router per dettagli progetti
*   **Form di Contatto**: Sistema di contatto integrato con validazione
*   **Design Responsivo**: UI moderna e adattiva costruita con **TailwindCSS** e componenti Material-UI

### 📱 Componenti Chiave
*   **Hero Section**: Sezione introduttiva con animazioni e call-to-action
*   **Timeline**: Visualizzazione cronologica dell'esperienza professionale
*   **Work Gallery**: Showcase progetti con slider e dettagli interattivi
*   **Music Carousel**: Integrazione playlist musicale personale
*   **Blog Section**: Sezione articoli e contenuti

## 🛠️ Tech Stack

Il progetto utilizza un moderno stack tecnologico per garantire performance e scalabilità:

*   **Core**: React 19, Vite
*   **Routing**: React Router DOM v7
*   **Styling**: TailwindCSS, PostCSS, Material-UI (MUI)
*   **Form Management**: React Hook Form
*   **HTTP Client**: Axios
*   **UI Components**: Material-UI Lab, Emotion (styled components)
*   **Icons**: React Icons
*   **Notifications**: SweetAlert2

## 🚀 Installazione e Avvio

Per eseguire il progetto localmente:

1.  **Clona il repository**:
    ```bash
    git clone https://github.com/tuo-username/newportfolio.git
    cd newportfolio
    ```

2.  **Installa le dipendenze**:
    ```bash
    npm install
    ```

3.  **Avvia il server di sviluppo**:
    ```bash
    npm run dev
    ```
    Il sito sarà disponibile su `http://localhost:5173`

4.  **Build per produzione**:
    ```bash
    npm run build
    ```

5.  **Preview build di produzione**:
    ```bash
    npm run preview
    ```
