# Portfolio - Antonio Cuoco

Benvenuti nel repository del portfolio ufficiale di **Antonio Cuoco**. Questo progetto non è solo una vetrina creativa.

Il sito combina un design "Awwwards-winning" con solide funzionalità full-stack, dimostrando competenze avanzate in frontend engineering, animazioni 3D e architettura cloud.

## 🌐 Live Demo
Il sito è visibile all'indirizzo: [https://antoniocuoco.it](https://antoniocuoco.it)

## ✨ Funzionalità Principali

### 🎨 Creative Portfolio
*   **Esperienza Immersiva**: Animazioni fluide e transizioni di pagina curate con **GSAP** e **Lenis**.
*   **Interfaccia 3D**: Elementi interattivi realizzati con **Three.js** e **React Three Fiber**.
*   **Design Responsivo**: UI moderna e adattiva costruita con **TailwindCSS**. Notevole l'uso di micro-interazioni e tipografia curata.

## 🛠️ Tech Stack

Il progetto utilizza un moderno stack tecnologico per garantire performance e scalabilità:

*   **Core**: React 18, Vite
*   **State Management**: Redux Toolkit
*   **Styling**: TailwindCSS, PostCSS
*   **Animations**: GSAP, Framer Motion, Lenis Scroll
*   **3D Graphics**: Three.js, React Three Fiber, Dreis,Node.js

## 🚀 Installazione e Avvio

Per eseguire il progetto localmente:

1.  **Clona il repository**:
    ```bash
    git clone https://github.com/tuo-username/newportfolio.git
    cd newportfolio
    ```

2.  **Installa le dipendenze**:
    ```bash
    npm install
    # oppure
    yarn install
    ```

3.  **Avvia il server di sviluppo**:
    ```bash
    npm run dev
    # oppure
    yarn dev
    ```

4.  **Build per produzione**:
    ```bash
    npm run build
    ```
